# 复现指南

## 可以复现与不能复现的部分

| 资产 | 可复现 | 说明 |
|---|---|---|
| 机械 CAD | 可以 | 包含 SolidWorks 源文件与 STL 导出 |
| PCB 制造 | 可以 | 包含 Gerber 包与 BOM |
| 地面站界面 | 部分 | 源码可运行，但曲线与命令是占位实现 |
| 箭载固件 | 不可以 | 归档中不存在 |
| 飞行数据 | 不可以 | 没有日志、标定或外场测试记录 |
| 数传距离 | 不可以 | 千米级只是未验证的设计目标 |

## 前置条件

- SolidWorks 2021 或更高版本，或能打开 `.SLDPRT` / `.SLDASM` 的查看器。
- FDM 3D 打印机与切片软件。
- 能接受 Gerber 包的 PCB 制造商。
- 运行地面站所需的 Python 3.11。
- 用于台架测试的 3.3 V 串口适配器。

## 1. 核对机械版本

从 `mechanical/source/formal/` 开始。总装配是
`装配/整体装配.SLDASM` 和 `装配/分体装配.SLDASM`。请保留原始中文零件名与
文件夹名，装配体按这些名称查找零件。如果重命名零件，需要在 SolidWorks 中
重新指定引用。

STL 导出位于 `mechanical/output/3dp/`，第二次打印的文件位于
`mechanical/output/reprint/`。归档没有记录打印参数。请根据实际载荷选择材料、
层高和填充率，并写入自己的打印记录。

## 2. 制造电子板卡

1. 把 `electronics/output/gerber/` 中的 9 个 Gerber 包发给板厂。
2. 按 `BOM/bill_of_materials.csv` 采购。16 行没有价格或供应商编号，下单前
   必须补齐。
3. 对照打印舱段检查板卡外形。实测尺寸列在 `docs/zh-CN/system_design.md`。
4. 焊接前检查金手指边缘和 FPC 连接器。

## 3. 装配与台架测试

1. 先不点胶，把各舱段堆叠起来检查对位。
2. 逐一对金手指接触点做通断测试。
3. 先用限流电源给板卡上电，再连接电池。
4. 确认 3.3 V 电源轨与传感器 I2C 地址。
5. 台架测试期间不要安装发动机或任何含能器件。

## 4. 运行地面站

```bash
cd software/ground_station
python -m pip install -r requirements.txt
python appMain.py
```

选择串口，以 9600 波特率打开，然后开始接收。归档代码解析 `X`、`Y`、`GX`、
`GY`、`GZ` 字段并写入 `data.txt`。六张图显示的是 `y = x^2`，不是实时数据。
OpenGL 立方体在归档代码中未启用。

## 5. 验证软件

```bash
python scripts/verify_theory/run_verification.py
```

测试覆盖姿态公式、互补滤波、建议帧格式、四元数约定、冯·卡门曲线和实测几何。
它不测试 GUI，也不测试任何硬件。

## 6. 飞行版本仍缺少的内容

- RP2040 固件与固定周期调度。
- `media/photos/project/telemetry_frame.svg` 中的分帧协议。
- 带时间戳的记录器与飞后回放工具。
- 链路预算、天线选型与外场距离测试。
- 解锁状态机、通断检查与发射检查表。
- 由具备资质的靶场安全人员批准的飞行试验计划。

## 安全

本仓库记录的是学生项目，不包含推进剂配方、点火电路或发射流程。没有具备
资质的监督、合法授权和合适靶场时，不得尝试飞行。
