# 理论审查与勘误记录

## 1. 审查范围与方法

审查对象为 `docs/archive/report/沙尘利“箭”.pdf` 与同名 DOCX，共 10 页。重点核对
姿态解算、互补滤波、坐标与单位、遥测协议、数据记录以及报告中的工程声明。
方法如下：

1. 逐段提取报告原文与内嵌公式图片。
2. 对可数值化的公式使用纯 Python 复算，脚本位于 `../scripts/verify_theory/`。
3. 对无法从归档材料确认的事实标记 `[待确认]`，不把设计目标写成实测值。
4. 保留原始报告，不覆盖 PDF/DOCX；修正内容只写入本文档、README 和验证脚本。

## 2. 统一约定

- 机体坐标系：$x$ 向前、$y$ 向右、$z$ 向上，右手系。
- 惯性坐标系：当地水平，$z$ 向上。
- 四元数：Hamilton 乘法，标量在前 $q=[w,x,y,z]$，主动旋转，机体系到惯性系。
- 角度单位：内部计算使用弧度，界面与本文使用度。
- 加速度单位：$\mathrm{m/s^2}$；重力取 $g=9.80665\ \mathrm{m/s^2}$。
- 报告没有明确写出上述轴向与安装方向，因此 E-01 仍为待确认项。

## 4. 对结论的影响

- **飞行试验**：E-16 把“进行过试飞”从报告声明提升为电视记录，但仍没有遥测日志；80% 是学生估计，千米级数传未被测量。
- **姿态显示**：E-02 会改变第二、三象限的横滚符号。原式在 $\phi=150^\circ$
  时显示 $-30^\circ$，方向相反。
- **俯仰与航向**：E-03、E-05 说明归档只能给出横滚/俯仰的静态估计；所谓
  “3D 姿态”实际是两自由度立方体，不含航向。
- **动态段**：E-06 表明起飞与主动段的姿态估计不可直接使用静态公式；需要
  飞行数据才能给出误差包络。
- **数传与记录**：E-07、E-08、E-11 将“千米级、鲁棒、精确记录”降级为设计
  目标或未实现项。README 的规格表已按“实测/设计目标/未验证”分列。
- **硬件口径**：E-09、E-10 不影响已解析的板卡尺寸与 BOM 成本，但会影响
  固件目标平台和气压换算，复现前必须确认。
- **数值结论**：本仓库没有改写报告中的任何实测数据，因为归档中没有可核对
  的飞行或标定数据。
