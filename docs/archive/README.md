# Archive

This directory preserves the original, unmodified project materials.

| Path | Contents |
|---|---|
| `report/` | Original report in PDF and DOCX, Chinese, 10 pages |
| `presentation/` | Original 18-slide defense presentation |
| `display_board/` | Original display-board text |
| `software_legacy/` | Earlier Theta / contest ground-station source, build outputs removed |
| `readme_original.md` | The one-line README that existed before reorganization |

## What was excluded

The following were left in the source folder and are **not** committed:

- PyInstaller `build/` and `dist/` trees (about 248 MB).
- `__pycache__/`, `.pyc` files and empty runtime `data.txt`.
- 75 SolidWorks lock files named `~$*`.
- Duplicate copies of the report, videos and CAD parts.

The source folder is `F:\Desktop\DustArrow X` on the author’s machine. It was
not modified. See `../../MIGRATION_NOTES.md` for the full path mapping.

## Integrity

Original documents are stored as-is. The report figures were extracted into
`../../media/photos/reference/` without editing their content; only the format
was converted to PNG where needed. No original file was overwritten.

## Line endings

Files in this directory keep their original line endings, which may be CRLF.
Active source, documentation and CSV files elsewhere in the repository use LF.
