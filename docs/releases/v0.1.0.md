# DustArrow Ground Monitor v0.1.0

**Date:** 2026-10-20

First packaged release of the DustArrow ground-station application. This is a
reproducible, one-folder Windows build of the PyQt5 GUI that receives, displays
and logs the X / Y / GX / GY / GZ telemetry fields from the rocket.

## Build environment

- Windows 11 (x64)
- Python 3.11.9
- PyInstaller 6.22.3
- PyQt5, matplotlib, NumPy, PySerial, PyOpenGL

The build is produced by `scripts/build_ground_station.py`, which runs
PyInstaller against `software/ground_station/appMain.py` and collects the
OpenGL and serial submodules. Build intermediates go to
`build/ground_station/` and the executable folder to `dist/`.

## Bundle contents

- `DustArrowGroundMonitor.exe` — windowed launcher (no console window)
- `QtApp/images/` — window icon and bundled image resources
- `README.txt` — run instructions
- `LICENSE` — MIT license text

## Run instructions

1. Unzip the archive.
2. Run `DustArrowGroundMonitor.exe`.
3. Connect the USB serial receiver and select its COM port in the drop-down.
4. Open the port at 9600 baud, 8 data bits, 1 stop bit, no parity.
5. Start the stream.

The application writes `data.txt` next to the executable while data is
received.

## Changes in this build

- The window icon is resolved from the PyInstaller bundle (`sys._MEIPASS`) when
  frozen and from the source tree when run directly.
- The windowed build redirects `stdout`/`stderr` to `devnull` so the
  application's runtime `print()` calls do not raise in a build without a
  console.

## Scope and limitations

This release packages the archived ground-station software as-is. The
application implements the text telemetry path documented in the repository;
the proposed CRC-16/CCITT-FALSE framing exists as a verification module and is
not wired into the GUI. No telemetry log or quantitative flight data from the
TV-documented test flight is bundled; see `docs/errata.md` item E-16.

The application source and documentation are MIT-licensed. Third-party
datasheets, programme stills and the contest logo are excluded from the
license.
