# Media

## Photos

- `photos/project/` — author’s renders, bench photos, PCB screenshots, report
  figures and GIFs. `banner.png` is the README banner.
- `photos/project/cad_renders/` — 26 CAD and PCB screenshots from the original
  `演示图片` folder, numbered in capture order.
- `photos/reference/` — figures and equations extracted from the report. They
  are the author’s own figures.

## Videos

`videos/` keeps the original files:

- `cfd_demo.mp4` — CFD demonstration with watermark.
- `cfd_demo_alt.avi` — the clean CFD animation used for the GIF.
- `canard_parachute_animation.mp4` — nose separation, canard deployment and
  recovery animation.

## GIFs

GIFs are stored in `photos/project/` with a poster frame. Specifications:

| File | Width | Frame rate | Size |
|---|---:|---:|---:|
| `cfd_demo.gif` | 880 px | 12 fps | about 1.0 MB |
| `canard_deployment.gif` | 800 px | 10 fps | about 2.0 MB |

Both loop, have no audio and are below the 10 MB limit. The poster files are
`cfd_demo_poster.png` and `canard_deployment_poster.png`.

## Rights
